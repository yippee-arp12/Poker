# CryptoLens — Live Crypto Analytics Dashboard

Live market data dashboard powered by CoinGecko public API.

## Features
- Live prices for top 100 coins (auto-refreshes every 60s)
- Market cap dominance chart (top 10)
- Top gainers & losers (24h bar charts)
- 7-day sparklines for every coin
- Fear & Greed index
- BTC & ETH dominance bars
- Sort by price, market cap, volume, % change
- Filter: All / Gainers / Losers / High Volume
- Search any coin

## Deploy to Vercel (free)
1. Go to vercel.com
2. Drag this folder onto the dashboard
3. Done — live in 30 seconds

## Data Sources
- [CoinGecko API](https://coingecko.com/api) — free, no key required
- [Alternative.me Fear & Greed](https://alternative.me/crypto/fear-and-greed-index/)
